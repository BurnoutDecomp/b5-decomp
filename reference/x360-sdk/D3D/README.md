# Xbox 360 SDK reference

These four files preserve superseded reconstructions for reference. The native Xbox 360 build selects the SDK `d3d9i.lib` provider for the five methods documented in `tools/x360_sdk_providers.json`. Do not compile these copies as competing definitions.

The two former source files are SDK-provided, not compile gains. The SDK-only provider link does not establish a game link or runtime behavior.
